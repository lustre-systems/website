# Drafts

Landing page experiments, kept for reference. Nothing here is built or deployed:
Astro only publishes `src/` and `public/`.

```sh
python3 -m http.server 4322 --bind 127.0.0.1 --directory drafts
```

- `opus-5-5/`: five directions (A, B, D, E, F). From lustre-clinic `landing/opus-5-5` (5317343).
- `sonnet-5-5/`: a live-demo landing page. From lustre-clinic `landing/sonnet-5-5` (464b9b3).
- `screenshots/`: copies of the app screenshots the drafts use.
